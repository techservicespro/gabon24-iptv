IPTV Gabon — GABON 24 et GABON 1ÈRE
Playlist M3U à héberger sur GitHub. Elle utilise le serveur Northflank pour résoudre les diffusions YouTube en direct.
Playlist
Fichier : `GABON24.m3u`
Adresse prévue après publication dans `techservicespro/gabon24-iptv` sur la branche `main` :
`https://raw.githubusercontent.com/techservicespro/gabon24-iptv/main/GABON24.m3u`
Fonctionnement
GABON 24 : utilise le direct YouTube via Northflank.
GABON 1ÈRE : fonctionne uniquement si la chaîne YouTube correspondante diffuse un direct à cet instant. La chaîne YouTube doit être vérifiée pour confirmer qu'elle diffuse bien le programme souhaité.
Si Northflank est arrêté ou si YouTube refuse l'extraction, les chaînes peuvent ne pas fonctionner.
GitHub héberge uniquement la liste M3U, pas les vidéos.
Mise à jour
Sur GitHub, ouvrir `GABON24.m3u`, cliquer sur l'icône crayon, remplacer le contenu par celui du nouveau fichier, puis valider avec Commit changes.
Ne pas remplacer les liens de flux par des adresses de pages Web YouTube.
